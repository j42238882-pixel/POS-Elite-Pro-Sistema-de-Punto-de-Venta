# 🎨 Módulo Tailwind CSS - POS Elite Pro

Este directorio contiene la configuración y los estilos base de Tailwind CSS para el proyecto.

## 📁 Contenido del directorio

```bash
tailwind/
├── tailwind.config.js    # Configuración de temas, colores y rutas de escaneo
├── input.css             # Directivas @tailwind y clases personalizadas
└── README.md             # Esta guía de uso
```

## 🚀 Comandos Rápidos

Para compilar el CSS utilizando Tailwind:

```bash
# 1. Visualizar archivos con Bash
ls -la

# 2. Entrar a la carpeta tailwind
cd tailwind

# 3. Compilar desde la raíz del proyecto
npm run build:css
```
